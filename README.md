# Applis Auxo Systems — page de téléchargement

Site public : https://ailabmanager-tech.github.io/auxo-apps/ (GitHub Pages, dossier `site/`).
Les installateurs sont dans les releases de ce dépôt ; le code source des applis reste dans leurs dépôts privés.

Publier une version : `./publier.py <neuroforge|reveil> <version> <dossier des installateurs>`.
Fiche d'un magasin en ligne → mettre son lien dans `site/versions.json` (`magasins.play`, `appstore`,
`microsoft`) : le bouton Installer y renvoie alors automatiquement.

Codes QR imprimables : `publicite/`. Fiches des magasins (textes, captures) : `magasins/`.
